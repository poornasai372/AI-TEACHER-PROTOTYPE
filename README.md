# AI Learning Lab — Overfitting Studio

## 📌 Project Overview

**AI Learning Lab — Overfitting Studio** is an interactive educational prototype that teaches students the concept of **overfitting** through investigation, experimentation, explanation, and application.

Instead of showing a definition first and asking the student to memorize it, the prototype makes the student **experience the problem first**.

The student acts like a **Model Doctor** who has to investigate an AI model that performs very differently on training data and new data.

The ultimate goal is:

> **By the end of the prototype, the student should be able to explain overfitting in their own words and recognize it in a new situation.**
